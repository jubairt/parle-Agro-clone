# Project Overview

This project recreates the Parle Agro corporate website homepage using frontend web development technologies.

The project includes:

- Responsive navigation bar
- Hero banner section
- About Us section
- Brands showcase
- News section
- Footer with contact details
- Animated rotating image effect
- Responsive Bootstrap layout
